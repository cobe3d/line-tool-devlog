LINE 訊息與相簿整理工具：開發紀錄

一個使用者用中文對 Claude Code 描述需求，經過四輪對話，做出一個 Windows 視窗工具：用關鍵字找聯絡人，篩選文字訊息、相簿與照片裡的文字，一鍵下載並整理成報告。這份紀錄寫下過程中的判斷和踩過的坑。

01需求怎麼長出來

一開始只是「想整理 LINE 的訊息和相簿」。需求在對話中逐輪變得具體，每一輪都讓工具多一層篩選。

第 1 輪：一鍵下載全部文字和相簿，也能指定聯絡人
Claude 先說明 LINE 沒有官方批次匯出和個人聊天 API，提出三種方案，建議「電腦版＋自動化＋本機整理」。
第 2 輪：用關鍵字搜尋聯絡人，符合的都下載
加入聯絡人關鍵字、確認清單、勾選後下載的流程。
第 3 輪：訊息和相簿也要能用關鍵字篩選
定出三層篩選：聯絡人 → 訊息 → 相簿，並規劃照片內文字辨識。也說清楚技術限制：LINE 只能整份匯出，所以要先下載再篩選。
第 4 輪：有電腦版、要視窗介面、要 OCR
開始實作。實際探索 LINE 介面，寫出解析器、報告、OCR、自動化和 GUI，在真實環境測完整流程。

心得：先用表格把選項和限制講清楚，讓使用者自己選，比直接開始寫程式省事。第 3 輪先說明「LINE 只能匯出整個聊天室」，後面就不用重做。

02怎麼使用

做好的工具是一個視窗程式。整個使用流程只有六步：

  1. 開啟 LINE打開 LINE 電腦版並登入。
    程式會操作這個視窗
  2. 啟動工具雙擊 啟動LINE整理工具.bat。
    第一次會自動安裝套件，約 1～2 分鐘
  3. 找聯絡人輸入關鍵字，按「搜尋聯絡人」，在清單勾選要下載的聊天室。
    也可以按「列出全部聊天室」
  4. 設定要下載什麼填訊息關鍵字、日期、相簿名稱；需要時勾選照片文字辨識。
    關鍵字留空就是全部下載
  5. 開始，放開滑鼠按「▶ 開始下載並整理」，程式會自己操作 LINE。
    按 Esc 可以隨時停止
  6. 看報告完成後打開「搜尋報告.html」，關鍵字會以黃色標示。
    也有 Excel 版和各聊天室的 txt

03技術路線

方案做法結論
官方手動匯出每個聊天室按「儲存聊天」、每本相簿手動下載可行但不能一鍵
第三方付費軟體讀手機備份聊天資料要交給第三方，不採用
讀取本機資料庫直接讀 LINE 的資料檔資料有加密，不嘗試破解
電腦版自動化＋本機整理用 Windows UI Automation 操作 LINE 的官方功能，下載後在本機篩選採用：只用官方功能，資料不離開電腦

OCR 選了 rapidocr（ONNX，離線、可 pip 安裝、支援中文）。比對文字時用 zhconv 把繁簡統一，因為辨識結果常是簡體字。

04探索 LINE 介面

寫自動化前，先用小腳本把 LINE 視窗的 UI Automation 樹印出來，一層層確認「哪些東西讀得到、哪些按得到」。

目標看到的結構能不能用
聊天室清單每個項目是 Button，名稱格式為 名稱, [N人,] [未讀數,] 預覽, 日期，全部項目一次讀得到可以，免捲動

05踩過的坑

滑鼠點擊落在別的視窗

嚴重
現象
第一次點聊天室，開到的是另一個群組；點「儲存聊天」卻打開了照片檢視器。
原因
LINE 被 Claude 視窗蓋住，座標點擊落在最上層的視窗。
解法
能用 Invoke 的地方一律不用滑鼠。非點不可時，先把 LINE 帶到前景，再用 WindowFromPoint 確認那個位置真的是 LINE，不是就不點。

背景送點擊沒有反應

已解
現象
用 PostMessage 對視窗送滑鼠訊息，LINE 完全不理。
原因
LINE 是 Qt 程式，忽略這類訊息。
解法
改用上面的「帶到前景＋位置檢查＋真實點擊」，執行時請使用者不要動滑鼠，按 Esc 可停止。

好友／群組分頁看起來有切，實際沒過濾

已解
現象
分頁回報「已選取」，但清單數量不變。
解法
不靠分頁，改用名稱後面的「N人」自己判斷是不是群組。

以為存檔不會跳視窗

誤判
現象
前兩次「儲存聊天」和「儲存全部」都成功了，看似 LINE 會直接存到「文件」資料夾。
原因
其實會跳出「另存新檔」或「選擇資料夾」視窗，是使用者在旁邊幫忙按了存檔。
解法
程式自動填路徑（檔名欄 AutomationId 1001，資料夾欄 1152，確定鈕 1）。測試前要先請使用者不要幫忙按。

點相簿封面會開照片，不是開相簿

已解
解法
改點封面下方的相簿標題。標題位置由「項目頂端＋封面寬＋37px」算出，因為最後一本相簿下面多了一段空白，用「底部往上」算會點到空白。

電腦版聊天記錄用空白分隔

已解
現象
格式是 20:53 王小明 內容，但名稱本身也可能有空白。
解法
先從「傳送圖片／貼圖」和「已加入群組」這類行收集真正的名稱，再用最長比對切開。另外用時間倒退來判斷多行訊息裡像「09:00 開會」這種文字。

套件裝到了看不到的地方

已解
現象
在 Claude 裡 pip install --user 的套件，落在桌面版的虛擬化 AppData，使用者自己雙擊執行時找不到。
解法
啟動檔第一次執行時先檢查套件，缺少的就自動安裝。

打開聊天室＝已讀

副作用
說明
自動化要打開聊天室才能匯出，有未讀訊息時對方會看到「已讀」。
解法
清單標出未讀數，開始前再提醒一次，並提供「略過有未讀訊息的聊天室」選項。

08安全設計

  • 選單項目白名單：程式不會碰「退出群組」、「刪除相簿」、「檢舉」等項目。
  • 點擊前檢查位置：不是 LINE 視窗就不點，避免誤觸其他程式。
  • Esc 可隨時停止；已下載的部分照常整理。
  • 所有處理都在本機完成，不會上傳任何聊天內容或照片。
  • 開發時產生的測試檔都放在暫存區；誤存到「文件」資料夾的測試檔也已經移走。

09想照著做的人

可以照這個順序對 Claude Code 說，每一步確認沒問題再往下：

STEP 1 · 釐清方案我想整理 LINE 的訊息和相簿，請建議方案，要能一鍵下載，也能指定聯絡人。
STEP 2 · 加上篩選聯絡人、文字訊息、相簿都要能用關鍵字搜尋，只下載符合的再整理。
STEP 3 · 指定形式我有安裝電腦版，要視窗介面，也要 OCR。
STEP 4 · 實機測試請先用「Keep筆記」測試匯出，測試時我不會去按任何對話框。
測試期間 LINE 會跳出存檔視窗，請讓程式自己處理，不要幫忙按，否則無法確認自動化真的有效。

也可以直接拿交接包：用 Claude Code 打開資料夾，請它先讀 CLAUDE.md，就能接續修改。

10限制與後續

  • 只支援 Windows 版 LINE、繁體中文介面；LINE 改版後可能要重新探索介面。
  • 聊天室裡直接傳、沒放進相簿的照片還沒有支援，而且這類照片過一段時間就會過期。
  • 螢幕縮放 100% 以外的環境還沒實測。
  • 部分群組相簿數為 0 的原因待確認。
  • 可以打包成 .exe，讓沒有 Python 的電腦也能用。
